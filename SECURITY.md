# Security

comls reads Windows device metadata without opening COM ports or changing device
configuration. Metadata is supplied by the operating system and installed drivers.
Verbose output can contain hardware identifiers; redact identifying values before
sharing logs or screenshots.

## Reporting a vulnerability

Please avoid disclosing exploit details in public issues.

If this repository's GitHub **Security** tab offers **Report a vulnerability**, use
that private reporting channel. Otherwise, check the repository owner's public
GitHub profile for a contact method to arrange private reporting. Private reporting
availability and a dedicated security contact are not guaranteed by this document.
If no private channel is available, a public issue requesting a private contact is
appropriate, without exploit details or sensitive data.

Include the affected comls version, Windows version, reproduction steps, and impact
through the agreed private channel. Test against the current source before reporting
when possible. This project does not promise response times or support for older
versions.
